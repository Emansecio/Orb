# Caça de bugs, só leitura — 07/11/2026

Relatório datado: confira no código antes de tratar como estado atual. Nada foi alterado no repositório durante a caça.

## Como foi feita

12 rodadas de agentes Sonnet, só leitura, cada achado conferido no código antes de entrar na lista. As rodadas alternaram fluxos de uso, varreduras de padrão (derivadas dos achados anteriores) e saturação (arquivos lidos inteiros). A caça parou na rodada 12, que leu inteiros os 23 arquivos que nenhuma caça tinha citado e não achou nada novo. Achados novos por rodada: 27, 24, 33, 35, 24, 3, 6, 3, 5, 5, 5, 0.

## Resumo

- 164 achados: 42 de gravidade média e 122 de baixa. Nenhum de gravidade alta.
- "confirmado" = o fluxo foi seguido no código até o erro; "provável" = falta conferir algo, dito no item.
- Fora do escopo (pedido do usuário): segurança. Quatro itens tocam permissões porque são perda funcional: con.1, mover.1, autoferramentas.2, aovivo-ajustes.1.
- Decisão de desenho, não bug: alcance.3. Itens de documentação: promessas.1–5.
